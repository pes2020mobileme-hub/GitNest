# GitNest

> The future of building happens together.

A modern developer platform landing page inspired by GitHub's design language — rebranded as **GitNest**.

## Features

- Dark theme matching modern developer tools
- Responsive navigation & hero section
- Feature cards, stats, and call-to-action
- Clean Inter font + smooth gradients
- Fully static — no build step required

## Preview

Open `index.html` in any browser.

## Live Demo

You can enable **GitHub Pages** to host this site:

1. Go to **Settings → Pages**
2. Source: Deploy from branch `main`
3. Folder: `/ (root)`
4. Save → your site will be live at  
   `https://pes2020mobileme-hub.github.io/GitNest/`

## Customization

All styles are in a single `<style>` block inside `index.html`.  
Change the brand name, colors, or copy freely.
